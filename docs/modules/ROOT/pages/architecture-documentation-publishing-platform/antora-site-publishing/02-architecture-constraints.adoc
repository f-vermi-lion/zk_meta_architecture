== 2.1 リポジトリ

* 統合サイト用の標準リポジトリ名は`zouchikikou-docs-site`とする。
* 各ソースリポジトリは統合用Antora playbookを持たない。
* playbook、共通UI、site側workflow、横断検査ツールはサイト用リポジトリへ置く。
* 初期構成はpublicな骨組みとし、private repositoryをcontent sourceに含めない。

== 2.2 buildと公開

* サイト生成の中心はAntoraとする。
* npmの標準buildコマンドは`npm run build`とする。
* 生成先は`build/site`とする。
* 公開先はGitHub Pagesとする。
* Pages publishing sourceにはGitHub Actionsを使う。
* Pagesへuploadする生成物には`.nojekyll`を含める。
* 標準経路では、サイト用リポジトリでStructurizr SVGを再生成しない。

== 2.3 正本

* playbook、UI、site側workflow、共通検査ツールはサイト用リポジトリを正本とする。
* 文書本文、図ソース、生成SVG、component descriptorは各content sourceを正本または管理元とする。
* `build/site`、Pages artifact、公開サイトは派生成果物であり、直接編集しない。
