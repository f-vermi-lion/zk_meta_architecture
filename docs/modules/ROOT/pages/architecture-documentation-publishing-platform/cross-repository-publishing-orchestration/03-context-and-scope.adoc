| 入力

== 3.2 対象境界

この文書は、各処理をどの順序で、どのrepositoryで、
どの成功条件の後に実行するかを扱う。

AsciiDocの書き方、Structurizr export、
日英checkerのissue判定、Antora page生成の内部は扱わない。
それらの処理が返す成功・失敗と、次の処理へ渡す入力だけを扱う。

== 3.3 現在と目標

現在、site側の``build.yml``と``publish.yml``は手動``workflow_dispatch``で動作する。
図生成reusable workflowと日英checkerも個別に実装されている。

一方、source側からsite側への``repository_dispatch``、
site側の横断検査呼び出し、権限・token、失敗通知はend-to-endで未実装または未決定である。
