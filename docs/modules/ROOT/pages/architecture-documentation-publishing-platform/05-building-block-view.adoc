== 5.1 全体構成

次は構成要素間の流れを示すテキスト概要であり、図の正本ではない。

[listing]
----
文書作成者
    |
    v
ソースリポジトリ群
  | 文書正本 / 図正本 / source側検査
  |
  | main更新 / 再生成依頼
  v
サイト用リポジトリ
  | content sources / 横断検査 / Antora build / Pages deploy
  v
GitHub Pages
  |
  v
文書サイト閲覧者
----

== 5.3 責務の境界

* 文書本文と図モデルの所有者はソースリポジトリである。
* サイト全体のcontent source、UI、build、deployの所有者はサイト用リポジトリである。
* source側検査は個別リポジトリ内で完結させ、複数リポジトリ横断の検査はサイト用リポジトリで行う。
* 公開HTML、生成SVG、artifact、logは派生成果物であり、正本と区別する。
* 各子文書は自領域の詳細を正本とし、他領域の詳細は`xref`で参照する。
