== 1.1 目的

Antoraサイト集約・GitHub Pages公開基盤は、
複数のソースリポジトリにある文書正本を一つの閲覧サイトへまとめる。

ソースリポジトリへ統合サイト固有の設定を分散させず、
サイト全体のcontent sources、UI、build、deployを
専用の`zouchikikou-docs-site`で管理する。

== 1.2 対象

* `zouchikikou-docs-site`リポジトリ
* Antora playbookとnpm build
* content sourcesの集約
* Antora UI、navigation、`.nojekyll`
* 手動build workflowとGitHub Pages publish workflow
* `build/site`、artifact、公開サイト

source側検査、図生成、日英検査の仕様、
リポジトリ間イベントとtoken / secretは関連子文書で扱う。

== 1.3 品質目標

[cols="1,3",options="header"]
|===
| 品質目標
| 説明

| 集約可能
| 複数componentの文書をplaybookのcontent sourcesとして取り込める。

| 小さく開始できる
| publicな一つのcontent sourceと手動buildだけでもサイトを生成できる。

| 再現可能
| lockfile、playbook、workflowから同じ静的サイトを生成できる。

| 公開結果を追跡できる
| build artifact、Actions log、Pages URLから結果を確認できる。

| 正本を混同しない
| 公開HTMLを直接編集せず、ソースリポジトリとサイト設定から再生成する。
|===
