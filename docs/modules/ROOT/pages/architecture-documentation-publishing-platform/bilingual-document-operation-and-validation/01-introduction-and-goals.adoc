== 1.1 目的

日英文書運用・検査は、英語での作成・AI支援と、
日本語での確認・閲覧を両立させる。

英語版を正本、日本語版を補助版として役割分担し、
対応するページの構造と言語metadataを機械的に確認できるようにする。

== 1.2 対象

* 英語正本と日本語補助版の役割
* Antora moduleによる言語別配置
* 対応ページの識別
* ``:lang:``属性
* ``tools/check-language-pairs``の入出力と失敗条件
* 草稿、公開、版確定での要求水準
* 対応言語ページへ移動する導線の未決定事項

翻訳内容の正しさや、二つのページが意味的に同一であることの完全保証は対象外とする。

== 1.3 品質目標

[cols="1,3",options="header"]
|===
| 品質目標
| 説明

| 正本が明確
| 内容が衝突した場合に英語版を正本として判断できる。

| 対応を識別できる
| 日英ページが同じ相対pathとfile nameで対応する。

| 欠落を検出できる
| 公開前に片方だけのpageと``:lang:``不一致を機械的に検出できる。

| 草稿を妨げすぎない
| 編集途中は片方だけの変更を許し、公開・版確定時に両版を要求する。

| 閲覧者が移動できる
| 公開サイトで正本と補助版の関係を理解し、対応ページへ移動できる。
|===
