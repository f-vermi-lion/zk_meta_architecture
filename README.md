# このディレクトリについて
ここでは造智機巧のアーキテクチャ文書についてのアーキテクチャやgit・GitHubリポジトリの分け方など、設計や開発についてのメタ的な設計について、日本語で文書化を行います。

## 構成
- meta_architecture
    - README.md
    - inbox.md  やった方が良さそうなことをとりあえず書き込んでやるかやらないか決めたら消す（何かを決定する、など）
    - tasks.md  やると決めたことをチェックリストにして出来たらチェックを入れる。
    - decisions/ 決定したことについて入れる。大まかな種類ごとに別ファイルにしておく。
    - decision_records/ 決定記録を入れる。自明なことまで書かなくてよい。
