== 4.1 同一componentのmoduleで分ける

同じ対象システムの文書を同一componentに保ちつつ、
英語と日本語を独立したpageとして編集できるようにする。

[cols="1,2",options="header"]
|===
| module
| 役割

| `ROOT`
| 英語正本

| `ja`
| 日本語補助版
|===

versionはcomponentの版を表すために使い、
言語を表すためには使わない。

== 4.2 pathを対応識別子にする

言語を除いたmodule配下の相対pathとfile nameを対応識別子とする。
翻訳titleや表示名に依存しないため、
ページtitleが異なっても機械的に対応を検査できる。

== 4.3 草稿と公開のgateを分ける

編集途中は片方のpageだけを更新してよい。
公開または版確定のworkflowでは、
両方のpageと正しい``:lang:``を要求する。

この区別により、翻訳待ちで草稿作成を止めず、
不完全な言語構成を公開時に見逃さないようにする。

== 4.4 小さな専用検査を作る

Antoraの標準buildだけでは日英pageの対応関係を要求できないため、
対応pathと``:lang:``だけを検査する小さなコマンドをサイト用リポジトリへ置く。

内容差分や鮮度は初期コマンドへ詰め込まず、
必要性と判定可能性を別途決める。
