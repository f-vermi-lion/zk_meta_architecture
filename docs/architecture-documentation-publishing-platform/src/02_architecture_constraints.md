## 2. 制約

### 2.1 技術的制約


| 制約                                 | 背景/説明                                |
| ---------------------------------- | ------------------------------------ |
| Arc42 型の文書                         |                                      |
| AsciiDoc 形式の文書ファイル                 |                                      |
| Structurizr DSL の図                 |                                      |
| 図のコード化                             | Structurizr以外も使いたくなってもコードとして扱える形式に限る |
| Structurizr のDSL→SVG変換機能           |                                      |
| DokToolChain の Arc42・アーキテクチャ文書管理機能 |                                      |
| Antora の複数リポジトリの文書集約、サイト構築機能       |                                      |
| GitHub Pages の静的ウェブサイトホスト          |                                      |

### 2.2 組織的制約


| 制約    | 背景/説明                |
| ----- | -------------------- |
| 製作者   | FとAIのみ。Fは低経済力で日本語話者。 |
| 開発ツール | VSCode、Codex、ChatGPT |

### 2.3 慣例


| 制約   | 背景/説明           |
| ---- | --------------- |
| 日英対応 | 図を含めて文書は日英対応にする |
